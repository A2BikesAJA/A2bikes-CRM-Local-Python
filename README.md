# A2bikes-CRM-Local-Python

## Shopify landing pages

This branch adds four conversion landing pages for the A2 Bikes Shopify store
(SP Performance, SP vs Quintana Roo, Financing/HSA-FSA, and Rogue), built as
Online Store 2.0 sections.

- Source: [`shopify/`](shopify/)
- Install & handoff guide: [`shopify/docs/INSTALL.md`](shopify/docs/INSTALL.md)

The section/snippet/asset/template files have been deployed into the unpublished
**"Why A2 — DRAFT (preview, do not publish yet)"** theme for preview. The live
theme was not modified and the draft theme was not published.
